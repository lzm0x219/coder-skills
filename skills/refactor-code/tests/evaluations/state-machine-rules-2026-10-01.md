## 带提示恢复与状态走查

第二代理的错误检查案例事先给出错误方向，明确记为带提示运行。原契约允许非整数乘积；错误断言在原实现与重构实现上均退出 1，实际 AssertionError 含 5.25。按原契约修正检查后两侧均退出 0，父级复验也通过。见 [规则报告](../evidence/rules-v2/report.md)、原错误检查、修正检查与四份日志。

代理发现恢复规则的一处措辞歧义：原句可能将依据原契约纠错也要求为契约变化。本次修正为两条明确分支；未改变业务契约。

依赖版本变化、不可比失败、未核验公共路径、制品缺文件、只有历史报告及用户改为只读这六个场景仅做状态转移走查，见规则报告。走查不等于这些场景已真实运行。
