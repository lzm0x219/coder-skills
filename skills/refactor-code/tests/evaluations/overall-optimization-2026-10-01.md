以下由 Codex 对优化后的文字规则进行语义走查，没有执行这些场景的新代理任务；运行证据见下一节。

| 已给定的事实 | 指针、动作与下一步 | 允许的结论 |
| --- | --- | --- |
| 只读评价，尚无有收益的结构改造 | S0 形成分析依据 → S5，读取完成判断 | 分析完成；源码指纹应保持 |
| 简单改名，消费者明确、必要观察有基线 | S1 建账，S2 明确名称和引用范围，S3 改动并检查 | 无需加载模块拆分或溯源分支；按实际结果交付 |
| 修改前缺私有依赖，必要集成无法运行 | 恢复的检查失败 → S1；核对环境恢复授权及隔离条件 | 无独立安全切片时阻塞；局部交付不能关闭必要集成观察 |
| 基线制品可导入，当前源码通过但制品缺文件 | 恢复的制品失败 → S3，修复构建并重验制品消费者 | 通过前该兼容项保持待证，不能称完成 |
| 失败输入或环境与基线不可比 | 检查失败 → S1，取得可比证据再分类 | 保持待证，尚不能认定旧失败或新回归 |
| 原有失败前后相同，已证明不交叉且切片通过 | 保留旧失败，继续当前状态 | 保留例外与影响边界，报告实际结果 |
| 用户修改输出与消费者，原检查失效 | 工作区变化 → S1，建立包含用户编辑的新基线 | 保留编辑和原始失败；新旧证据身份分开 |
| 目标与依赖同时变化 | 证据失效 → 最早受影响的 S0，再核对 S1 和后续切片 | 保留不相关证据；适用范围重新固定 |
| 基线和当前同样触发错误断言，原契约支持另一预期 | 保护检查的观察：保留原失败，按原契约纠正并重跑两侧 | 不以新实现输出自行改 oracle |
| 局部检查通过，但切片仍影响未验证公共状态 | 环境缺失与范围收缩：隔离条件未满足，回 S1 补证 | 原目标无可独立安全切片且不能补证时阻塞 |
| 用户在实施中改为只读或取消修改 | 目标/授权变化 → S0，立即执行新边界，保持工作区 | 停止新增源码修改；清理或撤销按用户指令 |
| 中断后只有历史完成报告，当前状态不明 | 中断恢复：核对仓库、工作区、环境，再按差异选状态 | 报告本身不证明完成；不重复已核实且不受影响的切片 |
