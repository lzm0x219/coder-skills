# 兼容基线

S1 从入口、消费者和变化路径选择观察，S3/S4 沿用同一兼容账。

## 兼容账

每项记录：观察与契约来源、受影响消费者、基线源码身份、输入/运行条件、预期或原结果、检查方法、当前结果及状态。源码身份包括用户已有编辑，用工作区差异或必要指纹标识；HEAD 只标识提交。基线可取原始工作区、核对过的只读副本或制品。

| 状态 | 证据要求 |
| --- | --- |
| 基线已建立 | 修改前取得可比观察，检查能区分目标差异；实施后仍须验证。 |
| 已验证 | 当前实现满足契约，前后对照或契约检查及相关消费者证据完整。 |
| 旧失败 | 两侧同一失败可复现，且本次影响已独立核查；保留例外与影响边界。 |
| 待证 | 缺基线/环境、不可比或未执行；明确阻断的观察，走恢复分支。 |
| 不适用 | 有调用/契约依据证明无受影响路径；未知仍记待证。 |

对齐影响结果的规模、版本、调度、构建选项与依赖，前后分别调用原始与当前实现。覆盖承诺契约、已发现消费者和用户要求的运行路径；拿不到任意第三方消费者只限定结论，缺本次必要观察或指定环境则待证。

此处基线是验证对照；正式配置基线另按项目控制要求处理，概念与出处见[W01](basis.md#w01-精确定位)。

## 观察细则

仅将本次受影响分支加入兼容账。

### 公开库、声明与制品

- 按契约、包导出与实际调用区分稳定入口和实现路径；承诺过的深层导入也属兼容范围，必要消费者未知则待证。
- 经原承诺入口核验导出名、模块路径、签名、泛型约束、可选性及类型/运行时导出，保留真实消费者。声明按解析类型和可赋值性比较，文本相等只证明文本一致。
- 移动路径同时检查源码与实际制品的导入解析、包导出、构建 glob、大小写、相对资源、动态加载及声明生成；必需文件进入实际制品。

### 数据、错误与副作用

保存字段、缺省、承诺顺序、编码、空值和异常输入的代表结果与边界反例。错误包含类型、消费者依赖的消息、抛出时机与副作用顺序；从调用方确认默认值、对象身份和惰性执行的隐含契约。

### 状态与调度

按实例/资源归属核验初始化、缓存寿命、清理与泄漏。覆盖双实例隔离、同实例订阅/请求共享、取消前后、重复关闭及失败传播；状态上移到模块时用反例检查共享范围。

调度/集合拆分核验事件与微任务顺序、快照时机、投递前成员检查、回调重入、取消再订阅、关闭后的排队任务及异常传播。可控调度用于缩小反例，原生调度或真实运行证明环境行为；两类证据分开记账。

### CLI、应用与服务

检查退出码、输出/交互、持久化副作用、请求响应、配置与资源路径。

### 性能约束

对承诺的复杂度、吞吐、延迟或资源预算在可比条件下测量，结论限定到实际输入和环境。

## 无法取得完整证据

待证项走[恢复](recovery.md)。分别标明静态、替代运行与样例对照的证明范围；未见差异只支持已执行的输入和条件。
