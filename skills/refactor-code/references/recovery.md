# 异常与恢复

保存当前观察、最后通过切片和失败命令，再按事实转移。保持工作区；撤回仅限可确认属于本次的修改，核对用户原编辑仍在。

## 检查失败

| 事实 | 动作与出口 |
| --- | --- |
| 同基线/输入/环境复现旧失败 | 核对与本次路径是否交叉，独立检查切片；不交叉且通过则继续，无法排除影响则待证。 |
| 基线通过，当前同一观察失败 | 回 S3，缩小到最近切片，修复新差异并重跑反例；受影响检查通过再推进。 |
| 原制品可用，当前缺文件/路径/导出 | 回 S3 修构建、资源或入口，重验实际制品消费者；源码通过只证明源码。 |
| 失败但两侧条件不可比 | 回 S1 补基线复跑、受控输入或环境证据，取得可比观察再分类。 |
| 修改前因依赖/权限/制品/配置缺失而无基线 | 按项目方法和授权恢复条件，回 S1 建基线；无法恢复走环境缺失分支。 |

重试应改变假设、输入、诊断或实现；同条件失败且无新证据时调查另一可证伪解释。关键依赖不可得时按[完成判断](verification.md#完成判断)交付阻断/部分结论。

### 保护检查的观察

同一检查先运行两侧，核对是否观察目标行为。纠正错误断言时给出原契约依据并重验两侧，保留首次失败；接受新预期需已确认的行为变化，当前实现输出不足以修改 golden/快照/断言。

## 环境缺失与范围收缩

列出受影响观察。可继续切片须在依赖与行为上独立可验，且不会破坏未验证路径的公共入口/状态。缩小范围 → S0 更新边界，再到 S1 建新基线；按完成判断分别报告已交付范围、原目标剩余项及解除条件。

## 工作区变化与证据失效

| 变化 | 返回状态 |
| --- | --- |
| 目标/授权改变 | S0；只读或取消请求立即生效，保留工作区，清理/撤销按用户指令。 |
| 基线/环境改变影响观察 | S1；仅失效对应兼容项。 |
| 方案不再满足职责/入口约束 | S2；更新方案与切片。 |
| 实现新增修改 | S3；重验受影响切片后进 S4。 |

多项变化先回最早受影响状态；不相关证据保留，身份按[兼容账](compatibility.md#兼容账)核对。无法安全分离用户和本次编辑时保留文件，暂停冲突切片并列明位置及待厘清意图。

## 中断恢复

用上下文或项目载体保存状态、范围/方案、兼容账、最后通过切片、未解问题与下一步。恢复先核对当前仓库、工作区和环境差异，再按上表转移；不受变化影响的通过切片复用，状态不明先补事实。
