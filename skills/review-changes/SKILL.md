# 审查变更

固定差异 → 追踪合同与消费者 → 应用触发细则 → 核实因果与反证 → 交付有界结论。用一份覆盖记录承载阶段和规则证据，最终报告保留作者可行动的问题与实际限制。

## S0 固定差异与执行边界

读取[范围与版本](references/review-method.md#scope)，确定比较语义、实际基线与目标、完整路径、内容身份和执行授权；按该节处理空差异、冲突、不可读内容及隔离验证。

出口 → 能列出纳入路径、未覆盖项和拟执行动作的授权依据，版本没有混读，禁止范围不会被直接或间接执行；未绑定的比较保持待定。

## S1 追踪合同与消费者

按[契约与覆盖记录](references/review-method.md#coverage)，为每个对象关联改变的不变量、真实入口/消费者、适用要求及实现落点，包含删除与未实现要求。合同区分必须、允许、禁止和未定义，核实等价保护与限定前提。

出口 → 完整变更清单中每个对象和相关验收条件有落点或具体缺口；缺口不妨碍检查其他对象。

## S2 选择并应用细则

读取[变化路由](references/routing.md)，匹配所有受影响类型和通用风险，逐条应用触发分支。未匹配变化执行 [F1](references/routing.md#f1)，检查预算与证据不足执行 [F2](references/routing.md#f2)、[F3](references/routing.md#f3)。按覆盖记录复用证据、处理交叉引用与引用环。

出口 → 每个对象的所有触发规则都有证据状态；已核验项可复核，未验证项保留具体缺口。

## S3 核实因果与反证

按[确认门槛](references/review-method.md#evidence)调查每个疑点。源码充分时直接引用；需要运行时使用已授权的隔离反例，按[运行记录](references/review-method.md#run-records)留存真实观察，并按 S0 登记验证产物。

出口 → 确认问题满足五项门槛；反证成立的疑点撤回或收窄；未核实的重要前提改为缺口。

## S4 交付并复核快照

按[分类与报告](references/review-method.md#report)去重、定位、定级，保留规范、需求和正确性的分别状态；复核快照，只重查失效证据。需归档或声明冻结时执行[冻结顺序](references/review-method.md#run-records)，使用宿主要求的输出格式。

出口 → 报告与覆盖记录一致，确认问题可行动，未验证项可追溯，快照有效；结论限于已核验范围。
