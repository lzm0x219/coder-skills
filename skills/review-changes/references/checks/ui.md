# 界面状态

行为按项目支持的设备和交互方式判断；视觉偏好仅作为获请求的建议，适用标准版本与等级查 [来源](../sources.md) 和项目要求。

<a id="u1"></a>

## U1 可达状态与用户动作

触发：条件渲染、加载/空/错误状态、按钮可用性或导航变化。

必须从真实入口走到改变的状态，列出该状态可用动作与后续终态；检查失败后能否恢复、空数据是否被误判加载、必要操作是否变得不可达。只检查本次影响的状态组合。

完成：每个改变状态有可达入口及动作结果，或具体的卡住/遗漏路径。静态截图不能证明状态转换，组件单测直接注入状态也不能证明真实入口能到达它。

<a id="u2"></a>

## U2 请求结果与页面身份

触发：请求参数、路由/用户切换、异步回填或视图状态写入变化。

必须把结果关联到发起时的页面/用户身份，检查切换后旧回调还能写入哪些数据；请求交错按 [A2 时序规则](async.md#a2) 执行。另查旧错误或 loading 清理是否覆盖当前请求的状态。

完成：迟到结果及清理只作用于所属视图，或有可达的旧数据/状态覆盖反例。取消请求只有在实际执行者和写入点都受约束时才是反证。

<a id="u3"></a>

## U3 表单提交与重复动作

触发：验证、提交锁定、保存/支付或重复点击处理变化。

必须核实用户输入到服务端接受的流程，追踪校验失败、请求中、成功和失败后的字段/按钮状态；重复触发涉及副作用时必须读取 [A3 重试与未知完成状态](async.md#a3)，用操作身份与重放证据核验。检查失败后是否仍能纠正并重试。

完成：约定的验证与提交状态成立，重复动作和恢复各有依据。前端禁用按钮不能代替服务端幂等保证；明确只读或无副作用操作不强加幂等键。

<a id="u4"></a>

## U4 交互语义与焦点

触发：可操作元素、标签、焦点、弹层或键盘处理变化。

必须按项目支持的输入方式核实动作是否可触发、名称是否可识别、焦点是否能进入/退出并在关闭后回到合理位置；删除原生元素行为时追踪其替代语义，检查视觉可见但键盘不可达的路径。

完成：改变的交互在声明支持的方式下有动作和焦点结果；实际缺少浏览器/辅助技术验证时写明限制。不能由正确 ARIA 字符串推定行为已验证，也不能无项目依据将个人布局偏好定为缺陷。

<a id="u5"></a>

## U5 视口、缩放与可见操作

触发：CSS、尺寸、定位、滚动、响应式、字体或层叠变化。

必须在支持的视口、方向、缩放与长内容下核实裁切、重排、覆盖及操作可达；检查固定栏、弹层、屏幕键盘和焦点滚入视图的组合。量测实际渲染，截图记录视口及状态。

完成：改变布局下的必要内容和操作可用，或具体遮挡路径。单一桌面截图不证明响应式，二维表格等标准例外须按适用要求判断；不能把个人审美作为阻断。

<a id="u6"></a>

## U6 颜色、名称与非视觉信息

触发：颜色、图标、图像、文本对比、错误标记或状态提示。

必须查真实前景/背景及交互状态、仅靠颜色表达的意义、替代文本与控件可访问名称；按项目采用标准的阈值/例外判断，状态通知核实实际辅助技术可感知性。

完成：改变信息在声明支持方式下可识别，或具体违反适用标准。工具只能证明其测量范围，CSS 色值或 alt 属性存在不证明整体可访问性；装饰图与信息图分别判断。

<a id="u7"></a>

## U7 媒体、运动与时间限制

触发：音视频、字幕、自动播放、动画、闪烁、倒计时或拖拽交互。

必须核实适用字幕/音频替代要求、暂停控制、reduced-motion 和非拖拽操作；时间限制、闪烁及目标尺寸查采用标准的实际条款与例外。

完成：受影响交互有相应操作和信息替代证据。动画存在不自动违反标准；不能用静态截图证明媒体控制、运动偏好或字幕同步。

<a id="u8"></a>

## U8 本地化与输入方式

触发：翻译、RTL、日期/数字显示、文本拼接、输入法或触摸目标。

必须核实完整字符串/复数、长文本、方向及输入法 composing 事件，检查键盘/触摸支持范围；底层编码/日期复用 [V2](semantics.md#v2)、[V3](semantics.md#v3)。

完成：改变的语言/输入类别有实际或明确限制的证据。不能以英文/ASCII 测试证明全部 locale，项目未支持的语言不强制扩展。
