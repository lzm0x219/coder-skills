# 信任边界

确认安全问题必须有实际攻击者输入、可达路径及越过的边界；源头的既有保护同样属于证据。

<a id="t1"></a>

## T1 身份来源与前置验证

触发：身份字段、token/session 解析、可信上下文或身份注入方式变化。

必须追踪身份来自已验证上下文还是请求可控字段，核实签名/会话校验实际在哪个入口运行及所有新增路径是否经过它。测试里的伪身份不能作为生产路径可信性的证明。

完成：每个受影响入口的身份来源和保护位置明确，或标出可控身份到受保护操作的路径。解析 token 不等于验证；反过来，上游已验证且不可绕过时不能重复指控下游没有再验证。

<a id="t2"></a>

## T2 对象与租户授权

触发：按 ID 读取/修改/删除、批量操作、租户选择或角色条件变化。

必须关联可信主体、请求对象及实际查询/更新谓词；检查读与写、单项与批量是否一致受约束。以当前用户请求另一主体对象的具体 ID 检查结果，不只测试“已登录”和对象存在。

完成：每条改变的受保护路径有对象级授权依据，或可复核越界结果。合法的公共资源或管理员跨域访问按明确政策判断；不能把登录成功当所有对象都授权，也不能无政策要求一切数据私有。

<a id="t3"></a>

## T3 输入到解释器/目标

触发：外部输入进入 SQL、命令、路径、模板、跳转或外部请求目标。

必须追踪可控输入如何成为数据、语法或资源目标，读取最终调用及该上下文的实际编码/参数化/允许范围；检查拼接的标识符、路径解析后的范围和可达外部目标。URL/字符串“经过校验”须核实该校验约束与最终解释一致。

完成：输入无法越过既定资源/语法边界的证据，或一条可达越界路径。不能因用了参数化 API 就忽略另行拼接的标识符，也不能仅凭字符串拼接宣布注入。

<a id="t4"></a>

## T4 数据出口与最小暴露

触发：响应字段、日志、错误细节、遥测、文件下载或缓存内容变化。

必须核实实际数据分类和接收者权限，追踪来源到序列化/日志的最终字段；检查失败与调试路径是否同样遵守脱敏或秘密处理规则。缓存键与隔离按 [D1](state.md#d1) 核验。

完成：新增出口只包含有明确允许依据的敏感字段，或有来源、接收者和政策支撑的暴露发现。不能把“仅在错误时打印”当作免检；没有分类政策时区分已知秘密与未确定敏感性，不凭字段名称编造法规结论。

<a id="t5"></a>

## T5 授权失败与旁路

触发：权限查询失败处理、默认角色、例外路径或认证绕过条件变化。

必须沿授权服务报错、权限为空与被明确拒绝三种受影响路径检查最终决定；追踪“开发/内部/健康检查”例外是否可由外部请求或生产配置触发。

完成：受保护操作在该政策定义的拒绝/失败条件下保持拒绝，例外有实际边界；或能证明错误被转成授权成功。明确允许公开的操作可降级，不能借它推定受保护写入也允许降级。

<a id="t6"></a>

## T6 密码学与秘密生命周期

触发：随机数、hash、加密、签名、密钥、密码保存或证书校验。

必须按实际安全用途核实算法/API 参数、熵来源、nonce/IV 唯一性、密钥获取/轮换/失效与验证失败行为；匹配版本的安全资料支持结论，比较和传输保护按具体威胁模型判断。

完成：安全用途的前提有证据，或存在可达破坏。非安全校验和不能按密码签名标准强行评价；自称加密、库函数存在或测试 round-trip 不证明真实性与密钥管理安全。

<a id="t7"></a>

## T7 滥用与受控资源

触发：外部可控上传、解压、正则、网络目标、注册或昂贵操作。

必须追踪谁能控制输入、放大因子、执行预算和拒绝位置，核实限制在消费资源之前且无入口旁路；资源复用 [R1](resources.md#r1)、[R2](resources.md#r2)、[R4](resources.md#r4)，目标访问按 [T3](trust.md#t3) 核验。

完成：具体威胁下的消耗受声明限额约束，或可达耗尽链成立。只有字符串长度限制不证明解压后限制；可信且有硬上限的输入是反证，不泛称所有正则存在 ReDoS。

<a id="t8"></a>

## T8 数据留存与删除

触发：数据生命周期、删除/导出、备份、遥测或第三方共享。

必须以项目政策为来源追踪数据副本、删除传播、保留例外及访问控制；检查索引/缓存/备份的实际期限与允许恢复语义。

完成：声明的生命周期有证据或具体不符。没有政策时保留要求缺口，不编造法定义务；业务删除成功不自动证明所有副本立即消失。
