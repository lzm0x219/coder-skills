# 表示与语义

取值边界按 [B1](behavior.md#b1)、[B2](behavior.md#b2) 核验，传输表示按 [C2](contracts.md#c2) 核验。

<a id="v1"></a>

## V1 数值与单位

触发：金额、计量、计数、位运算、舍入或精度转换。

必须追踪单位、表示范围、NaN/无穷、溢出及舍入发生点，核实不同运算顺序是否改变可观察结果。金额政策从业务来源提取，不自行规定小数位。

完成：受支持值有一致的计算/转换，或具体精度/溢出反例。不能将任意浮点使用判为缺陷；只有可达输入和承诺精度足以确认。

<a id="v2"></a>

## V2 日期、时区与日历

触发：解析/显示日期、日界线、重复/不存在本地时间、日历区间。

必须区分 instant、本地日期及持续时间，核实 timezone、DST、闰日、月底与 locale 来源；存取及显示边界使用同一语义。期限复用 [Q5](reliability.md#q5)。

完成：变化覆盖其允许的日期类别且调用者意义一致。UTC 不是所有业务日期的默认答案；无时区对象的含义须查契约，不能自行假设。

<a id="v3"></a>

## V3 字符、编码与规范化

触发：文本切片/长度、编码、大小写、排序或 Unicode 比较。

必须核实字节/code point/grapheme 的实际需求，测试受支持的多字节、组合字符及规范化；身份比较还查冲突和后端存储语义。

完成：输入到显示/存储符合声明规则。ASCII 成功不证明 Unicode 成功；不强制所有标识符做同一种规范化，否则可能产生身份合并。

<a id="v4"></a>

## V4 路径与平台差异

触发：路径、文件命名、权限、大小写、符号链接、换行或 OS 命令。

必须查支持平台的分隔符、保留名称、大小写规则与字节编码，核实受支持的换行/空格路径在参数传递或目录枚举中不被拆分、截断或另作语法解释。涉及命令或流式枚举时检查参数数组、NUL 安全枚举或等价保护；直接文件 API 同样以路径是否完整保留为准。路径授权复用 [T3](trust.md#t3)。

完成：支持平台有对应依据，或明确平台缺口。单主机运行不能替代跨平台结论；不能把 shell 字符串的 JSON 序列化当 shell escaping。
