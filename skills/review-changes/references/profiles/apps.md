# 移动与桌面

按实际 OS/SDK 官方资料核实平台行为，参考入口见 [来源](../sources.md)。

<a id="p1"></a>

## P1 生命周期与状态恢复

触发：前后台、窗口/Activity 重建、进程终止、会话或持久状态。

必须跟踪 transient 与 durable 状态、重建后任务/订阅归属，以及内存对象丢失后的恢复；迟到结果按 [U2](../checks/ui.md#u2)，资源按 [A5](../checks/async.md#a5)。

完成：声明支持的生命周期变化有证据，或具体丢失/重复路径。页面卸载模拟不证明 OS 杀进程；未执行真机/模拟器时说明缺口。

<a id="p2"></a>

## P2 系统能力与权限

触发：相机、定位、文件、通知、剪贴板、快捷键或系统凭据。

必须检查能力声明与运行时授权、首次拒绝/永久拒绝/撤销、硬件不可用和受支持 OS 版本；权限变化不得由 UI 开关替代系统核验。

完成：允许/拒绝路径有实际来源及恢复方式。API 成功 mock 不证明 manifest、entitlement 或 sandbox 正确；不得扩大权限来绕过验证失败。

<a id="p3"></a>

## P3 离线同步与本地数据

触发：离线写、同步、冲突、身份切换或本地数据库升级。

必须核实操作身份、冲突政策、恢复网络后的顺序、重复与删除 tombstone；用户切换后的数据隔离按 [D1](../checks/state.md#d1) 和 [T2](../checks/trust.md#t2)，重放按 [A3](../checks/async.md#a3) 和 [D5](../checks/state.md#d5)。

完成：改变的离线/在线组合满足政策，或具体丢失/跨用户路径。只有在线成功不能证明同步；产品未承诺离线写时不强制添加。

<a id="p4"></a>

## P4 安装、升级与系统集成

触发：安装器、签名、应用沙箱、关联协议、深链接、自动更新或原生库。

必须核实实际产物、安装/旧版升级、入口注册和支持架构；签名/更新身份按 [S4](../checks/supply-chain.md#s4)，ABI 按 [M5](../checks/structure.md#m5)。

完成：改变平台的实际安装/系统入口有证据，或精确环境缺口。开发环境启动不是已签名安装验证；平台认证必须由实际渠道结果支撑。
