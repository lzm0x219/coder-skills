# 数据与 AI

数据和模型要求由实际用途决定，参考入口见 [来源](../sources.md)。

<a id="e1"></a>

## E1 数据总体、质量与血缘

触发：数据源、join/filter、去重、分母、窗口、标签或指标改变。

必须定义总体、时间窗口、粒度、主键、缺失/迟到/重复政策及来源版本；追踪 join 的基数、过滤顺序与输出意义。数值/日期复用 [V1](../checks/semantics.md#v1)、[V2](../checks/semantics.md#v2)。

完成：受影响指标可从来源重算，或具体丢失/放大/错分母证据。若总体未定义，保留语义缺口；不能由行数一致推定数据内容一致。

<a id="e2"></a>

## E2 增量与可重放流水线

触发：checkpoint、watermark、批处理、分区、回填或重跑。

必须核实处理时间/事件时间、状态与输出提交、重跑身份、迟到数据及部分失败恢复；消息提交按 [Q2](../checks/reliability.md#q2)，迁移按 [D4](../checks/state.md#d4)。

完成：允许的重跑和迟到路径符合一次性/重复政策。新建空表测试不证明历史回填，最终一致声明必须有收敛路径和期限依据。

<a id="e3"></a>

## E3 学习与评估隔离

触发：训练/验证切分、特征、阈值、模型选择或性能指标。

必须核实时间/实体隔离、特征在预测时可得、标签来源和 preprocessing fit 范围；使用与实际任务匹配的指标、基线和样本覆盖，区分调参集与最终评估。

完成：评估输入/版本/总体可追溯，或具体泄漏/无效比较。高准确率不证明稀少类别有效；同一 holdout 反复调参不能当独立最终评估。

<a id="e4"></a>

## E4 模型产物与运行一致性

触发：模型、tokenizer、特征顺序、推理依赖、量化或检索索引。

必须核实产物及数据/schema 的版本绑定、训练/服务变换一致性、缺失/异常输入和支持硬件；检索更新/删除和用户权限复用 [D1](../checks/state.md#d1) 和 [T2](../checks/trust.md#t2)。

完成：对应产物组合及改变分布有证据。固定 seed 不保证跨硬件确定性；小样本或 CPU 模拟不证明 GPU 性能、生产漂移或整体模型质量。

<a id="e5"></a>

## E5 Agent、生成输出与工具授权

触发：prompt、检索上下文、工具、记忆、生成后执行或结构化输出。

必须沿以下链路核验，每段保留合同、实际路径与证据：

1. **上下文与提议**：区分不可信内容与可信指令，分别核实上下文来源、候选操作、权限判定和副作用消费者的合同。检查不可信输入是否被提升为可信任务、改变实际提议或使合法任务结果丢失。下游拒绝只限定已观察后果，不能撤销已证实的上游合同违例；反证必须满足当前合同要求的来源分层、提议行为、授权判定及结果处理，无副作用只证明其对应部分。
2. **校验到执行**：分别确认 schema 已定义、实际调用校验、执行的是校验后值；逐条追踪默认对象、类型强转、校验绕过和失败恢复路径。按合同检查合法、缺字段、错误类型、额外字段、拒绝、malformed、fallback 和重试输入，直到权限判定与副作用消费者；不适用分支说明理由。schema 常量、prompt 禁令、parser 返回、生成成功、执行 status 或 consumer exit 0 均不能代替运行时校验证据。
3. **授权与副作用**：追踪模型可影响的操作到实际权限检查，核实输出失败/拒绝、重试重复副作用与预算。失败或拒绝后查是否制造新操作、跨越原身份/权限/预算，以及真实副作用记录是否变化；拒绝状态与无副作用分别取证。身份、授权及注入按 [T1](../checks/trust.md#t1)、[T3](../checks/trust.md#t3)，重复与成本按 [A3](../checks/async.md#a3) 和 [R4](../checks/resources.md#r4)。
4. **证据范围**：只有本地固定 proposal 或有限 schema 子集时，注明实际宿主/执行器、工具权限、输入范围及涉及时的模型配置；未取得的运行事实保留为缺口，结论只覆盖已证边界，不推断真实模型或全标准可靠。

完成：攻击/失败输入到工具边界有证据及受限后果。prompt 中写“禁止”不证明强制授权；几次生成成功不能推出全输入可靠或模型安全。不得以验证为由真正执行未授权工具动作。
