# 库与工具

分发按 [L3](../checks/delivery.md#l3)，公开兼容按 [C1](../checks/contracts.md#c1)、[C4](../checks/contracts.md#c4) 核验。

<a id="k1"></a>

## K1 命令行与进程契约

触发：参数、stdin/stdout/stderr、exit code、信号或交互提示。

必须使用承诺的调用方式核实默认/冲突参数、空输入/管道、TTY 与无 TTY、错误退出及中断；机器输出与提示分流，静默/JSON 模式不能混入进度文本。

完成：真实子进程调用的输出与退出满足契约，或具体自动化破坏。直接调用内部函数不证明 CLI；没有支持交互模式的工具不强制 TTY UI。

<a id="k2"></a>

## K2 编译与转换语义

触发：parser、resolver、代码生成、优化、source map 或诊断。

必须核实受支持语法/配置的输入到输出意义，查错误定位及转换顺序；优化要求保持声明的外部行为，生成结果按实际消费者验证。

完成：改变的语法/转换有可比基线与输出消费证据。快照相同不一定等价，快照不同也不必然错误；只比较字符串不能证明编译结果运行正确。

<a id="k3"></a>

## K3 文件操作与插件

触发：格式化、编辑、批量改写、watcher、插件或工作区发现。

必须核实作用范围、忽略规则、符号链接、原子写入及中断恢复；检查 dry-run 真正无写入，插件权限按 [S2](../checks/supply-chain.md#s2)，路径按 [V4](../checks/semantics.md#v4)。

完成：受影响文件及失败后状态符合契约，或具体越界/损坏路径。审查验证默认使用临时副本；备份文件存在不证明恢复完整，明确 destructive 模式按其授权判断。
